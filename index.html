AI ที่ใช้ออกข้อสอบ

ใส่ครั้งเดียว ระบบจำไว้ในเบราว์เซอร์เครื่องนี้ และส่งตรงไปยังผู้ให้บริการ AI ที่เลือกเท่านั้น

ฐานข้อมูล Firebase (ไม่บังคับ)

ถ้ายังไม่เชื่อมต่อ ข้อสอบจะถูกเก็บในเบราว์เซอร์เครื่องนี้ ถ้าเชื่อมต่อ ข้อสอบจะถูกบันทึกลง Firestore

วิธีเชื่อมฐานข้อมูล Firebase (ทำครั้งเดียว)
  1. เข้า console.firebase.google.com ล็อกอินด้วยบัญชี Google แล้วกด สร้างโปรเจกต์ (แพ็กเกจฟรี Spark ใช้ได้)
  2. ในหน้าโปรเจกต์ กดไอคอน </> (Web app) ตั้งชื่อแอป แล้วคัดลอกก้อน firebaseConfig ที่แสดงให้
  3. ไปที่ Build → Authentication → Sign-in method แล้วเปิดใช้ Anonymous
  4. ไปที่ Build → Firestore Database → Create database เลือก production mode และภูมิภาค เช่น asia-southeast1 (สิงคโปร์)
  5. เปิดแท็บ Rules ของ Firestore วางกฎด้านล่างแทนของเดิม แล้วกด Publish 
    rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid}/exams/{examId} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}
  6. วาง firebaseConfig จากข้อ 2 ในช่องด้านล่าง แล้วกด เชื่อมต่อ เมื่อสำเร็จจะขึ้นสถานะสีเขียว และเมนูซ้ายล่างขึ้น "☁ เชื่อม Firebase แล้ว"

ข้อควรรู้: ข้อมูลผูกกับเบราว์เซอร์ (ล็อกอินแบบ Anonymous) ถ้าล้างข้อมูลเว็บหรือเปลี่ยนเครื่องจะมองไม่เห็นข้อสอบเดิม · ถ้าเปิดไฟล์ตรง ๆ แล้วเชื่อมต่อไม่ผ่าน ให้รัน python3 -m http.server ในโฟลเดอร์ไฟล์ แล้วเข้า http://localhost:8000/exam-generator.html · apiKey ใน firebaseConfig ไม่ใช่ความลับ ความปลอดภัยมาจาก Rules · API Key ของ AI ไม่ถูกส่งขึ้น Firebase
